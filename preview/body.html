用 Go 写原生桌面应用。

macOS 上 Cocoa + Metal · Windows 上 Win32 + Direct3D 11 · Linux 上 X11 + Vulkan。
没有 WebView，没有浏览器引擎，也没有捆绑的运行时。

官网 · 文档 · 组件 · 案例 · English

Viva 是面向原生桌面应用的 Go 框架。它直接通过各操作系统自己的接口和 GPU 绘制窗口、文字与组件，所以应用只链接系统框架和 Go 运行时，别无其他。空闲时完全不做事。

1.6 MiB 剥离后的可执行文件  ·  0 空闲时的 GPU 提交  ·  0.0% 空闲 CPU
在 M0 Mac 上实测。每个数字都引自仓库里的报告——你可以自己重新跑一遍。

围绕什么构建

原生，不是浏览器
macOS 调用 Cocoa 与 Metal，Windows 调用 Win32 与 Direct3D 11，Linux 调用系统自带的 XCB 与 Vulkan 库。没有 WebView，也不捆绑渲染器。 		空闲就是空闲
未变化的一帧不做布局、不重建场景、不向 GPU 提交任何东西。没有后台定时器，也没有轮询。
组件归你所有
viva add 把组件的 Go 源码复制进你的项目。没有组件注册表，运行时也没有样式表解析器——就是你可以随意修改的 Go 代码。 		无需窗口即可测试
无头驱动用显式调用运行真实的绘制器、输入路由和焦点规则，测试不需要桌面会话。
一套 API，三个原生后端
在 macOS、Windows 和 Linux 上拥有相同的组件、输入、文字与无障碍语义。 		实测，可复现
二进制体积、空闲开销和场景耗时都引自标明机器与构建的基准报告。

快速开始

# macOS / Linux
brew install vivaui/tap/viva

# Windows
scoop bucket add vivaui https://github.com/vivaui/homebrew-tap
scoop install viva

viva doctor       # 这台机器准备好了吗？
viva init hello   # 一个可直接运行的项目，含窗口与测试
cd hello && viva dev .   # 热重载：保存文件，窗口保留状态

预编译压缩包（带 SHA256SUMS）在每个发布的 releases 页面。需要 Go 1.26 或更新版本；机器上没有时，viva 会下载一次工具链。

用 Go 写一个窗口

package main

import (
	"fmt"
	"log"

	"github.com/vivaui/viva/app"
	"github.com/vivaui/viva/ui"
)

type model struct {
	clicks int
}

// page 声明窗口的内容。每次重绘都会运行它并读取 model；
// 点击会修改 model，随后的一次重绘把结果显示出来。
func (m *model) page(c ui.C) {
	ui.Column(c).Fill().Pad(24).Gap(12).Children(func() {
		if ui.Button(c, fmt.Sprintf("Clicked %d times", m.clicks)).Clicked() {
			m.clicks++
		}
	})
}

func main() {
	m := &model{}
	if err := ui.Run(app.Config{Title: "Hello", Width: 480, Height: 240}, m.page); err != nil {
		log.Fatal(err)
	}
}
